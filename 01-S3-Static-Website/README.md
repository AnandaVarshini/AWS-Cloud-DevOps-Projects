# Tailstore – E-Commerce Static Website

A responsive e-commerce website built using HTML, CSS, JavaScript, and Tailwind CSS. The project provides a modern online shopping interface with product browsing, product details, cart, checkout, and user registration pages.

## 🚀 Features

- Responsive e-commerce homepage
- Product listing and shopping pages
- Product detail page
- Shopping cart
- Checkout page
- User registration page
- Responsive navigation
- Product categories and images
- Modern UI using Tailwind CSS
- Static website deployment using AWS S3

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Tailwind CSS
- AWS S3
