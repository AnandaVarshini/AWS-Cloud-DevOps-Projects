\# EC2 Linux Server — AWS Cloud Practice



\## Overview



This project demonstrates the deployment and basic administration of a Linux server using Amazon EC2.



\## AWS Services Used



\- Amazon EC2

\- Amazon VPC

\- Amazon Security Groups



\## EC2 Configuration



\- Operating System: Amazon Linux 2023

\- Instance Type: t3.micro

\- Region: US East (N. Virginia)

\- Access Method: SSH

\- Security Group: EC2 security group

\- SSH Port: 22



\## Tasks Performed



\- Launched an Amazon EC2 instance

\- Connected to the Linux server using SSH

\- Practiced Linux file and directory commands

\- Created and managed files and directories

\- Practiced users and groups

\- Configured file permissions

\- Used `tar` for file compression and archiving

\- Installed and worked with Apache web server

\- Worked with the `/var/www/html` directory
